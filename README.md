MoodMate – Smart Day Planner

MoodMate is a smart day-planning project developed to make planning outings easier, more personalized, and convenient for individuals as well as groups.

It helps users plan their outings based on their mood, preferences, budget, and location. For group outings, it also helps identify a convenient midpoint between members and explore suitable places and transportation options.

Features

- Mood-Based Planning: Select a mood to personalize outing suggestions and activities.
- Budget Selection: Choose a preferred per-person budget from predefined options or enter a custom budget.
- Group Planning: Plan outings with multiple members by considering their individual starting locations.
- Smart Midpoint: Calculate a geographical midpoint to help group members find a convenient meeting location.
- Place Recommendations: Explore places based on mood, preferences, budget, and location.
- Smart Itinerary: Create structured outing plans with suggested activities and timings.
- Public Transport: Explore public transportation options for reaching the selected destination.
- Private Transport: Access private travel options such as driving and cab services.
- Weather Information: Access weather information relevant to the selected location.
- Plan Management: Save, view, and manage previously created outing plans.
- Plan Sharing: Share plans using public links.
- User Profiles: Manage user information and access personal plans.
- Admin Dashboard: Role-based access with user management, plan monitoring, and activity logs.

⚙️ Running the Project

Prerequisites

- Node.js and npm installed.
- Git installed.
- Firebase project configuration set up.

Steps to Run

1. Clone the repository:
   
   git clone https://github.com/diyakini19/MoodMate.git

2. Open the project folder in VS Code.

3. Open the integrated terminal at the project root directory.

4. On Windows, execute the following command:
   
   .\start.bat

This starts the frontend and backend in separate terminal windows and opens the project in the browser.
